# Frontend

React + TypeScript + Vite. Ver el [README de la raíz](../README.md) para cómo correrlo.

`src/types/change_unit.ts` es **generado** desde `schemas/change_unit.schema.json` — no
editar a mano. Regenerar con `npm run generate:types` (o `make generate-types` desde la raíz)
después de cualquier cambio al modelo `ChangeUnit` en el backend.
